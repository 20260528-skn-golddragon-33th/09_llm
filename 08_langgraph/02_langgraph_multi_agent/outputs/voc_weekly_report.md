# 고객센터 주간 VOC 보고서

## 주간 운영 요약

이번 주 고객센터는 결제 문의가 가장 큰 비중을 차지한 가운데 모바일 결제 오류와 배송 추적·배송지 변경 관련 미해결 VOC가 확인되었다. 특히 우선순위가 높은 미해결 이슈와 SLA 초과 건에 대한 신속한 후속 조치가 필요하며, 결제 오류 재발 여부와 배송 처리 흐름을 함께 점검해야 한다.

## 주요 VOC

### 미해결 사례

- `T004` 결제 · high: 모바일 결제 단계에서 반복 오류
- `T007` 배송 · high: 출고 완료 후 배송 위치 확인 불가
- `T011` 배송 · medium: 배송지 변경 요청이 주문에 반영되지 않음

### 분석 결과

- 모바일 결제 단계에서 반복 오류가 발생해 결제 문의 증가의 주요 원인으로 판단되며, 재발 여부에 대한 지속적인 모니터링이 필요하다.
- 배송 분야에서는 출고 이후 위치 확인 불가와 배송지 변경 미반영 사례가 반복되어 배송 추적 정보와 주문 변경 반영 절차의 점검이 요구된다.
- 미해결 VOC 가운데 우선순위가 높은 이슈가 포함되어 있어 고객 불편과 운영 리스크가 상대적으로 큰 상태다.

## 권장 조치

- 모바일 결제 오류와 배송 위치 확인 불가 등 우선순위가 높은 미해결 이슈를 최우선으로 처리하고 고객에게 진행 상황을 안내한다.
- 배송 추적 연계 상태와 배송지 변경 반영 절차를 점검해 관련 미해결 문의의 재발을 방지한다.
- SLA 초과 원인과 미해결 건의 잔여 처리 일정을 확인하고, 담당 부서 간 후속 관리 체계를 강화한다.
